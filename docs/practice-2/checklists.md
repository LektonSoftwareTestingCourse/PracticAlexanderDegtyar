# Чек-листы периферийных сервисов СМП

## 1. Чек-лист дымового тестирования

### 1.1 Инфраструктура

- [ ] PostgreSQL принимает подключения, миграции выполнены
- [ ] RabbitMQ принимает подключения, Management UI открывается,
успешно создаются transaction-log, card-notifications

### 1.2 Доступность сервисов

- [ ] Gateway возвращает код 200 на health-check
- [ ] Switch возвращает код 200 на health-check
- [ ] Terminal Simulator возвращает код 200 на health-check
- [ ] Merchant/Acquirer возвращает код 200 на health-check
- [ ] Transaction Logger возвращает код 200 на health-check
- [ ] Bin Lookup возвращает код 200 на health-check
- [ ] Notification Service возвращает код 200 на health-check
- [ ] Web Dashboard загружает страницу


## 2. Чек-лист критического пути

### 2.1 Приём и маршрутизация

- [ ] Терминал берёт карты из Card Management и отправляет транзакции через Gateway
- [ ] Gateway отклоняет некорректное тело запроса
- [ ] Switch определяет банк-эмитент по BIN
- [ ] Неизвестный BIN отклоняется без резервирования средств

### 2.2 Решение эмитента

- [ ] Карта с достаточным балансом и лимитами одобряется
- [ ] Отказы по статусу карты, сроку действия, балансу и лимиту различаются по коду ответа
- [ ] Ненайденная карта отличима от недоступности Card Management
- [ ] Одобренная транзакция получает RRN и authCode

### 2.3 Движение средств

- [ ] При одобрении баланс уменьшается на сумму транзакции
- [ ] Счётчики лимитов растут на ту же сумму
- [ ] При отказе баланс и счётчики не меняются
- [ ] Возврат зачисляет сумму обратно и снимает её из учёта лимитов

### 2.4 Доставка результата

- [ ] Switch публикует транзакцию в очередь до ответа клиенту
- [ ] Журнал сохраняет транзакцию с корректной суммой, RRN и результатом
- [ ] Повторная доставка той же транзакции не создаёт дубликат
- [ ] Карточное событие доходит до Notification Service

### 2.5 Отказ зависимостей

- [ ] При остановленном Card Management транзакция отклоняется, средства не резервируются
- [ ] При остановленном Bin Lookup авторизация продолжается используя данные Bin в Switch
- [ ] Если очередь не подтвердила публикацию, резерв откатывается
- [ ] После восстановления зависимости система работает без перезапуска
